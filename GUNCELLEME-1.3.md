# VardiyaCep v1.3 — Ağustos / Önbellek Kesin Düzeltmesi

1. GitHub deposunda **Add file → Upload files** seçin.
2. Bu paketteki `app.js`, `index.html` ve `service-worker.js` dosyalarını yükleyip eskilerin üzerine yazın.
3. **Commit changes** butonuna basın.
4. 1-2 dakika sonra tarayıcıda şu adresi açın: `https://beyzatuzcu.github.io/vardiyacep/?v=130`
5. Sayfanın en altında **v1.3** yazısını kontrol edin.
6. **Dosyayı değiştir** ile Excel'i yeniden seçin.

Bu sürüm eski Mart verisini cihazdan otomatik temizler ve dosya adındaki `AĞUSTOS` bilgisini güçlü ay kanıtı olarak kullanır.
